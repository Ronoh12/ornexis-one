# ADR-0001 — Platform Name

**Status:** Accepted

**Date:** 2026-08-09

---

# Context

The software project originally started as an enhancement of the AGE-SET community management system.

As the architecture evolved, it became clear that the platform would support multiple organizations, multiple industries, and reusable business modules.

The original name no longer represented the scope of the product.

---

# Decision

The official product name shall be:

# ORNEXIS ONE

The company name remains:

# ORNEXIS Technology Ltd.

AGE-SET becomes the first reference implementation and first customer of the platform.

---

# Consequences

Future software development will:

- Use ORNEXIS ONE branding.
- Support multiple organizations through multi-tenancy.
- Build reusable modules rather than customer-specific systems.
- Maintain a single configurable platform.

---

# Alternatives Considered

- AGESET V2
- ORNEXIS Community Platform
- ORNEXIS ERP

These were rejected because they either limited the scope of the product or did not communicate the long-term platform vision as clearly as ORNEXIS ONE.
